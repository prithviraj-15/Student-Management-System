## 🎓 Student Management System

A simple and user-friendly Student Management System built using Flask (Python), HTML, CSS, and SQLite.
This project allows users to manage student records efficiently with basic CRUD operations.

---

🚀 Features

- ➕ Add new student details
- 📝 Edit existing student information
- ❌ Delete student records
- 📋 View all students in a structured table
- 💾 Data stored using SQLite database

---

🛠️ Technologies Used

- Frontend: HTML, CSS
- Backend: Python (Flask)
- Database: SQLite

---

📂 Project Structure

Project/
│── static/          # CSS files
│── templates/       # HTML files
│   ├── index.html
│   ├── add.html
│   ├── edit.html
│── app.py           # Main Flask application
│── students.db      # SQLite database

---

⚙️ How to Run the Project

1. Clone the repository:

git clone https://github.com/your-username/student-management-system.git

2. Navigate to the project folder:

cd student-management-system

3. Install dependencies:

pip install flask

4. Run the application:

python app.py

5. Open in browser:

http://127.0.0.1:5000/
